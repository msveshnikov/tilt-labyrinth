# Tilt Labyrinth

A low-poly 3D tilt-maze puzzle in Godot 4.7 (GDScript only). You tilt the board to roll the coloured balls, and every ball has to end up in the pocket of its own colour.

**▶ Play: https://severance.lol/2/** · **Android APK: https://severance.lol/2/TiltLabyrinth.apk**

## Features

- Tilting board (AnimatableBody3D), balls are RigidBody3D with CCD, Jolt physics at 120 Hz.
- Phone tilt: native `Input.get_gravity()` on Android; on the web it falls back to the browser's `devicemotion` / `deviceorientation` through `JavaScriptBridge`. Auto-calibration at level start, the **Калибровка** button, dead zone, smoothing, portrait lock, and a virtual joystick when there's no sensor.
- Coloured pockets, holes, up to 4 balls per level, stars for beating par, saved progress.
- Menus, settings, sound and vibration.
- **32 levels** that get harder as you go: bigger boards, more balls, more holes and fewer shortcuts.

## Controls

| Device | Tilt | Other |
|---|---|---|
| Phone | tilt the phone; on-screen joystick if the sensor gives no data | **Калибровка** = current pose is level, **Заново** = restart |
| PC | arrows / WASD, or drag with the left mouse button | `C` calibrate, `R` restart |

## Run

Open the folder in Godot 4.7+ and press Play (`scenes/main.tscn`).

## Levels

Levels are JSON files in `levels/`, named `level_01.json`, `level_02.json`, …

```json
{
  "name": "Первые шаги",
  "grid": ["#####", "#.S.#", "#####"],
  "balls": [{ "color": "red" }]
}
```

Grid: `#` wall, `.` floor, `S` ball spawn, space or `O` no floor (a hole). One character is one 1×1 cell, and row 0 is the far edge of the board. Pockets: `r` `b` `g` `y`. Ball colours: `red`, `blue`, `green`, `yellow`.

Levels are generated by `python tools/gen_levels.py` (deterministic, one seed per level). To add a level, append a row to `LEVELS` there and rerun it. The game counts `level_NN.json` files on its own, so you don't need to change any code.

## Tuning

- `scripts/autoload/settings.gd` holds the max board tilt (18°), sensitivity and axis inversion. These are saved to `user://settings.cfg`.
- `scripts/autoload/tilt_input.gd` holds the phone tilt for full board tilt (20°), the dead zone and smoothing.
- `scripts/ball.gd` holds mass, friction, bounce and damping.
- `project.godot` sets gravity (12) and physics at 120 Hz.

## Export

```sh
godot --headless --export-release "Web" build/web/index.html
godot --headless --export-debug "Android" build/android/TiltLabyrinth.apk
```

- **Web:** threads are off, so no COOP/COEP headers are needed. It uses the Compatibility renderer. Copy the *contents* of `build/web/` to the server folder; the tilt sensor needs HTTPS. Deploy: `scp build/web/* ubuntu@severance.lol:/var/www/severance/2/`
- **Android:** debug-signed (no release keystore configured), arm64, portrait, VIBRATE permission. The motion sensors are switched on in `project.godot` (`input_devices/sensors/enable_*`). Godot 4.3+ turns them off on Android by default, and the APK gets no tilt data without them. No runtime permission is needed. Deploy: `scp build/android/TiltLabyrinth.apk ubuntu@severance.lol:/var/www/severance/2/`

## Structure

```
scenes/   main.tscn (everything else is built in code)
scripts/  main.gd, board.gd, ball.gd, level_loader.gd
          autoload/  settings.gd, tilt_input.gd, sfx.gd, progress.gd
          ui/        hud.gd, screens.gd, star_row.gd, touch_joystick.gd, ui_theme.gd
levels/   level_01.json … level_32.json
tools/    gen_levels.py (level generator)
build/    export output (git-ignored)
```
